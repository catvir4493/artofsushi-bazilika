# 订桌后台：Google 表格 + Apps Script

网站的订桌表单把数据发到这里的 Apps Script，脚本写进 Google 表格，并发两封邮件：一封通知店里（回复地址是客人邮箱），一封自动回执给客人。表格里的「Foglalás」菜单可以给选中的那一行发确认或拒绝邮件。

## 一次性设置（约 15 分钟）

所有步骤都用**店里的 Google 账号** `artofsushi.szentistvan@gmail.com` 做。客人收到的邮件会从这个地址发出。

> 免费 Gmail 账号用 Apps Script 发邮件每天上限约 100 封。每个订桌发 2 封（通知 + 回执），确认时再发 1 封，所以每天大约能处理 30 个订桌。超过的话订桌仍会写进表格，只是邮件发不出去，需要换成 Google Workspace。

1. 在 Google Drive 新建一个表格，命名为 `Foglalások – Bazilika`。
2. 菜单 **扩展程序 → Apps Script**，打开脚本编辑器。
3. 删掉默认的 `Code.gs` 内容，把本文件夹里的 `Code.gs` 全部粘贴进去。
4. 左侧齿轮 **项目设置**：
   - 勾选「在编辑器中显示 appsscript.json」，把本文件夹的 `appsscript.json` 内容粘贴进去（时区 Europe/Budapest）。
   - 在「脚本属性」里添加：
     - `NOTIFY_EMAIL` = 接收订桌通知的邮箱，`artofsushi.szentistvan@gmail.com`
     - `TURNSTILE_SECRET` = Cloudflare Turnstile 的 Secret key（可以等 Cloudflare 开好再加）
5. 回到表格，刷新页面，顶部出现「Foglalás 订桌」菜单。点 **Beállítás / frissítés · 设置/更新**，按提示授权。会自动：
   - 建好表头、状态下拉、颜色
   - 建好未来 7 天的日期表
   - 设置每天 0:10 自动删除已过去那天的订单（GDPR），以及 14 天以前的「Mentés 备份」备份页
6. 脚本编辑器右上角 **部署 → 新建部署 → 类型：Web 应用**
   - 执行身份：**我**
   - 有权访问的用户：**任何人**
   - 部署后复制「Web 应用 URL」（以 `/exec` 结尾）。
7. 把这个 URL 填进网站 `js/main.js` 顶部的 `CONFIG.FORM_ENDPOINT`，提交并推送。
8. 在网站上用自己的邮箱提交一次测试订桌，检查：表格多一行、店里收到通知、自己收到回执；再用菜单发一次确认邮件。

> 以后修改 `Code.gs` 后，要在 **部署 → 管理部署 → 编辑 → 版本：新版本** 重新部署，URL 不变。

## 更新脚本（Code.gs 有改动时）

1. 表格里 **扩展程序 → Apps Script**，把编辑器里的 `Code.gs` 全部删掉，粘贴仓库里最新的 `apps-script/Code.gs`，点保存。
2. 右上 **部署 → 管理部署** → 选中现有部署 → 铅笔（编辑）→ 版本选 **新版本** → 部署。网址不变，网站不用改。
3. 回到表格刷新页面，菜单 **Foglalás 订桌 → Beállítás / frissítés · 设置/更新** 跑一次：表头和状态会变成匈中双语，旧状态自动转换，K/L/M 三列隐藏，“今天/明天”视图重建。

## 日常使用

- **Foglalások（总预约单）**：所有未来的预约，按日期、时间自动排序。**第一列是状态**，新订单「Új 新订单」是橙色。
- **最快的确认方式**：在「Új 新订单」的状态格下拉选 **Visszaigazolva 已确认**（或 **Elutasítva 已拒绝**）→ 弹框确认 → 邮件马上发出。点「否」状态会改回「新订单」。已经发过确认/拒绝的订单再改状态，只改状态，不会再发邮件。其他状态（已到店、未到店）只改状态。
- 选中那一行任意格子 → **Foglalás 订桌 → ✓ Visszaigazolás küldése · 发送确认**：给客人发确认邮件，状态变「Visszaigazolva 已确认」。
- **✕ Elutasítás küldése · 发送拒绝**：发“没有空桌”的邮件，状态变「Elutasítva 已拒绝」，这条不再出现在日期表里。
- **日期表（如 11.08）**：从今天起未来 7 天每天一张，实时读取总表，只用来看和抄本子；修改都在总表里改。
- 每天 0:10 自动删掉已经过去那天的预约和日期表，并补上第 7 天。
- 店里通知邮件里直接点「回复」就是回给客人。客人在英文页面下单，所有邮件自动用英文。

## 客人的后续邮件（「Levél 客人邮件」列）

客人订完桌后如果又发邮件（新邮件，或者直接回复确认/回执邮件），总表的 **Levél 客人邮件** 列会出现蓝底的
`✉ 11.09 14:32 · 邮件开头几句…`，点一下就在 Gmail 里打开那封邮件。日期表（如 11.08）里也有这一列。

- 脚本每 10 分钟查一次 Gmail 收件箱（过去 30 天），按订单里的邮箱地址匹配；只看订桌之后来的邮件。
- **在 Gmail 里回复了客人** → 下一次检查时自动消失（最后一封是我们发的 = 已回复）。
- **在 Gmail 里把邮件归档** → 也会消失（当作已处理）。
- **电话里解决了、不需要回邮件** → 选中那一行，菜单 **Foglalás 订桌 → ✉ Levél kezelve · 邮件已处理**。之后客人再来新邮件还会重新标出来。
- 想马上看：菜单 **✉ Levelek ellenőrzése most · 立即检查邮件**。
- 限制：客人用**另一个邮箱**写信的话匹配不上（只能认订单里填的那个地址）；已拒绝的订单不标。

### 客人在「备注」里提了要求

订桌时备注（Egyéb kérés）不是空的，这一格会显示橙底的 `📝 Válaszra vár · 备注待回复: 备注内容…`。脚本自己加的「⚠ 同一客人当天已订」不算。
客人之后又来了邮件的话，显示蓝色的 ✉ 那条（更要紧）；邮件处理完，如果备注还没回，会变回 📝。

📝 会在下面几种情况消失：
- **发送确认 / 拒绝时回复**：这一行有备注的话，会先弹出一个框显示客人的备注，在里面写回复（按客人的语言写，HU 写匈牙利文，EN 写英文）。回复会和备注一起写进确认/拒绝邮件。留空就只发确认，📝 保留。
- **在 Gmail 里给这个客人写过信**（订桌之后，包括回复店里收到的“新订单”通知邮件），下次检查时自动消失。脚本自动发的回执/确认/拒绝邮件不算。
- **不需要回复的备注**（比如“生日”）：选中那一行 → **✉ Levél kezelve · 邮件已处理**。

### 备注太长看不全

总表里「Egyéb kérés 备注」超过 25 个字的，格子右上角会有一个黑色小三角。**点一下那一格（或鼠标移上去）**，会弹出一个小方块显示全文。日期表（如 11.09）里的备注列会自动换行，直接显示全文。

### 在表格里直接回复客人

选中那一行 → **Foglalás 订桌 → ✉ Válasz a vendégnek · 回复客人**。弹出的框里会显示客人的备注和最新来信，下面写回复（EN 订单写英文，HU 订单写匈牙利文），确认后发出。
称呼（Dear … / Kedves …）、订单信息（日期、时间、人数、地址）和落款会自动加上，只写正文就行。
客人之前来过邮件（格子里有 ✉ 链接），回复会接在 Gmail 里那封邮件下面；否则发一封新邮件「About your booking / Foglalásával kapcsolatban」。发出后 ✉ / 📝 标记马上消失。

第一次启用：粘贴新 `Code.gs` → 新版本部署 → 表格里跑 **Beállítás / frissítés · 设置/更新**。这次会要求多一个
“读取 Gmail” 的授权（脚本只在店里账号里搜订单客人的邮件，不发也不删），点允许即可。设置会自动建好每 10 分钟的定时任务。

## 字段（总预约单）

| 列 | 说明 |
|---|---|
| Dátum / Időpont | 用餐日期、时间 |
| Név / Létszám | 姓名、人数 |
| Telefon / Email | 电话、邮箱 |
| Egyéb kérés | 客人备注 |
| Állapot | 状态：Új · Visszaigazolva · Elutasítva · Megjelent · Nem jelent meg |
| Levél 客人邮件 | 客人订桌后发来、还没回复的邮件（自动，点开是 Gmail），见下方说明 |
| Beérkezett / Nyelv / Azonosító | 提交时间、语言、编号，**默认隐藏**（右键列标 → 取消隐藏） |

不要手动删除或移动列，否则脚本会写错位置。

## 防垃圾 / 安全

- 表单里有一个隐藏字段，机器人填了就直接丢弃；页面打开不到 3 秒就提交的也丢弃（机器人看到“成功”，但什么都不记录）。
- 限流：全店每小时最多 20 个新订单，同一个邮箱或电话每天最多 3 个（`CFG.MAX_PER_HOUR` / `MAX_PER_GUEST_DAY`）。超过时网站提示客人打电话。这样别人刷表单也耗不光 Gmail 每天约 100 封的额度。
- 客人填的姓名里不能有网址；备注里有网址时，备注照样进表格，但不放进发给客人的自动回执（防止别人借我们的邮箱给陌生人发广告）。
- 以 `=`、`+`、`-`、`@` 开头的内容会作为纯文本写进表格，不会被当成公式执行（防“公式注入”偷表格数据）。
- 设置了 `TURNSTILE_SECRET` 后，每个提交都必须通过 Cloudflare Turnstile 验证；同时要在 `js/main.js` 填 `CONFIG.TURNSTILE_SITEKEY`。两个要一起填，只填一个会导致订桌失败。
- 表格只共享给需要的人（店里账号 + 老板），**不要**开「知道链接的任何人可查看」。
